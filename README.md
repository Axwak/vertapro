# Verta Pro

Conversor de PDF para imagens, imagens para PDF, imagens para imagens e análise de PDF.

## Sobre este repositório

Este repositório é destinado à distribuição de instaladores e à documentação pública do Verta Pro. O código-fonte da aplicação não é disponibilizado aqui.

## Download

Para obter um instalador:

1. Abra a seção **Releases** deste repositório.
2. Escolha a versão estável mais recente.
3. Em **Assets**, baixe o arquivo de instalação com extensão `.exe`.

Os arquivos **Source code (zip)** e **Source code (tar.gz)** são gerados automaticamente pelo GitHub e NÃO são instaladores do Verta Pro.

> Se ainda não houver uma Release publicada, o instalador ainda não está disponível neste repositório.

## Funcionalidades

### PDF para imagens

Converte páginas de PDFs em imagens. A interface permite escolher o formato e os parâmetros compatíveis, incluindo resolução de renderização e opções de cor.

### Imagens para PDF

Cria documentos PDF a partir de imagens, com possibilidade de organizar a sequência e reunir imagens em um documento.

### Imagens para imagens

Converte arquivos entre os formatos oferecidos pelo aplicativo, com opções de processamento e metadados conforme o formato escolhido.

### Análise de PDF

Apresenta informações das páginas e estimativas de bitmap para auxiliar na escolha da resolução antes da conversão. A estimativa não representa o tamanho final do arquivo nem a memória total do processo.

## Instalação

1. Baixe o instalador nos Assets de uma Release.
2. Salve seus trabalhos e feche o Verta Pro, caso esteja aberto.
3. Execute o instalador.
4. Confira o diretório de instalação e conclua o assistente.
5. Abra o aplicativo pelo atalho criado.

Consulte as notas da Release para requisitos, alterações e eventuais limitações específicas da versão.

## Manual

O manual acompanha a aplicação. Use o botão **Manual** ou a tecla **F1** para consultar as orientações das ferramentas.

## Atualizações

As versões publicadas ficam na seção **Releases**. A integração do verificador de atualizações está sendo configurada e validada; sua disponibilidade depende da versão instalada.

Antes de atualizar, aguarde o término de conversões e salve seus trabalhos.

## Relatar um problema

Se a aba **Issues** estiver habilitada, abra um relato contendo:

- Versão do Verta Pro.
- Versão do Windows.
- Ferramenta e formato utilizados.
- Passos para reproduzir o problema.
- Mensagem de erro completa ou captura de tela.

Não publique senhas, tokens, dados pessoais nem documentos confidenciais. Caso use um arquivo de exemplo, confira se ele pode ser compartilhado publicamente.

## Privacidade

As conversões do aplicativo são realizadas localmente. Quando habilitada, a verificação de atualizações acessa os serviços de distribuição para consultar versões e baixar instaladores.

## Licença e distribuição
